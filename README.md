**정직한 음성 결과.** test 에서 **부피 단독 기준선이 `full` 모델보다 LAA-vs-CE AUC 가 높다** — `volume_only` **0.6013** vs `full` **0.5909**.
dev 에서는 `full` 이 +0.084 앞섰는데 역전됐고, GT 마스크 오라클에서도 같은 방향이다(`volume_only` **0.6351** vs `full` **0.6234**) — 즉 분할 품질 탓이 아니다.
test 의 유일한 비편향 추정치는 Δ(`full` − `volume_only`) = **−0.010 [−0.195, +0.170]** 이다 — 이 구간은 dev 의 +0.084 도 0 도 포함하므로, test 80명은 dev 의 우위를 **재현하지도 반증하지도 못했다**.
남는 사실은 둘이다: 점추정은 기준선 쪽으로 기울었고, dev 에서 CI 가 0 을 제외했던 우위([+0.021, +0.149])는 test 에서 확인되지 않았다.
**크기 지름길이 가장 약한 축에서 이 모델은 특징 1개짜리 기준선을 넘지 못했다.** E1 을 성공으로 주장하지 않는다.
같은 방향의 **두 번째 음성 결과**: 크기를 뺀 `scale_invariant` 세트는 dev 에서 LAA-vs-CE **0.6434** 로 "위치·뭉침이라는 해부학 신호가 남는다"고 해석됐으나(A6), test 에서는 **0.4234 [0.281, 0.577]** 로 무너졌다 — 그 해석은 test 에서 지지되지 않는다.
SVO 의 높은 AUC(dev CV 0.85)는 모델의 병인 판별력이 아니라 **TOAST 정의상 "병변 <1.5 cm"** 라는 라벨 정의의 재현이며,
헌장에 "어떤 문서에서도 SVO AUC 를 판별력의 근거로 인용하지 않는다"고 사전에 못박아 두었다.

### 1. 특정 벤더에서 전멸한다 — 평균 Dice 0.683 뒤에 숨어 있던 실패

### 2. 소병변은 "못 그리는" 게 아니라 "못 찾는" 것 — 통념을 데이터가 반박했다

<2 mL 구간 Dice 0.538 은 ≥50 mL 의 0.849 대비 확연히 낮다. 통상 "작아서 경계를 못 그린다"고 해석하지만, 분해해보니 아니었다.

- <2 mL 구간에서 **시드당 8~10명이 정확히 Dice 0**이고, **이들을 제외하면 0.62~0.65** 로 2–10 mL 구간과 **같다**.
- 찾아낸 소병변의 **예측/GT 부피 비는 1.00~1.19 — 과소분할이 아니다.**

그래서 "과소분할이니 FN 을 무겁게 하자"는 개입은 **전제부터 틀렸고, 실제로 악화됐다**:

| 가설 | Δ(<2 mL Dice) | Δ / 시드SD | 판정 (사전 등록 3시드 규칙) |
|---|---|---|---|
| 해상도 192² | −0.008 | — | 효과 없음 |
| 2.5D 인접 슬라이스 (4ch / 6ch) | +0.004 / −0.004 | 0.29 | 효과 없음 |
| **Tversky (FN 가중) / focal-Tversky** | **−0.028 / −0.022** | −2.03 | **악화** (예측 부피 1.28~1.55배로 팽창) |
| 소병변 오버샘플링 `inv_volume^1.0` | +0.034 | 2.46 | 효과 있음, 단 **ICC 0.867 → 0.834** |
| 소병변 오버샘플링 `inv_volume^0.5` | +0.024 | 1.75 | **임계 미달** (5시드에서는 2.19 — 사후 분석) |

판정 규칙(3시드, 기준선 시드 SD 의 2배)은 **실험 전에** 정했고, 기준선 시드 SD(0.0138)는 5회 반복으로 먼저 측정했다.
추천 설정 `inv_volume^0.5` 는 **사전 등록 규칙을 통과하지 못했다**(1.75 SD). 5시드 보충 분석에서만 2.19 SD 이므로
**"규칙을 통과한 개선"이 아니라 "후보"** 로 보고한다. 그 5시드 기준으로는 <2 mL 0.5430 → **0.5733**(짝지은 CI [+0.006, +0.061]),
전체 0.6822 → 0.6929, ICC 0.8782 → 0.9134 로 **모든 보고 지표가 함께** 움직인다.
메커니즘도 측정했다 — **5시드 전부 Dice 0 인 하드 플로어가 7명 → 4명**으로 줄고, 찾아낸 병변의 Dice 는 불변이다.
**더 잘 그리는 게 아니라 못 찾던 3명을 찾는다.**

두 분석 모두 최종 모델을 바꾸지 않았다. `configs/seg_unet2d.yaml` 활성값은 무변경이고,
이 코드 변경 뒤 기본 설정으로 재학습해도 `best.pt` 가 **바이트 동일**하게 재현된다(sha256 `e10d9268…`).

## 에이전트 구성 — 서로를 반박하게 만든 8개
에이전트 이름·모델 구성은 참조 구성을 그대로 쓰고 주제만 교체했다. 핵심은 개수가 아니라 **서로 다른 모델이 서로의 결론을 뒤집은 기록**이다:

- **Astra → A1**: "민감도·특이도를 보고하라"는 P0 제안을 **"이 데이터에서는 정의가 성립하지 않는다"**(음성 환자 0명)로 반박 → 특이도는 NaN 으로 출력하고 보고하지 않기로 확정.
- **A2 → A6**: 성공 기준 "크기 제외 macro AUC > 0.60" 이 **부피 특징 1개(0.650)로 이미 통과**됨을 측정 → A6 가 자기 프로젝트의 기준을 폐기하고 E1/E2/E3 로 교체.
- **A3 → A4**: A3 가 "클립 ±6 이 병변을 포화시킨다"를 발견하고 **미수정으로 이관** → A4 가 clip 10 으로 val Dice +0.088 을 확인.
- **A5a(외부 Codex) → A5b(Fable)**: 17건의 독립 지적을 A5b 가 항목별로 판정(동의 13·부분동의 4) → 좌우축 버그 수정, "test 를 읽지 않았다"는 문구 정정.

| 에이전트 | 모델 | 담당 | 상태 / 주요 성과 |
|---|---|---|---|
| **A1** 주제·포지셔닝 | Opus | JLK 공고·제품군 확인, README 평가 | ✅ JBS-01K 와 1:1 과제 대응 확인. 갭 P0 3건(DICOM, 2.5D/3D, 민감도·특이도 보고) 지적 → 민감도는 `metrics.py` 에 반영, 특이도는 음성 환자 0명이라 **계산 불가**(Astra 반박, NaN 으로 출력) |
| **Astra** 방향성 교차검증 | Fable | 주제 탐색·대안 데이터셋·범위 판정, A1 결론 반박/동의 | ✅ **현 방향 유지+범위 축소** 판정. A1 P0 중 DICOM·특이도 반박(음성군 없음), 2.5D 는 P1. SVO 가 부피만으로 분리됨(중앙값 1.13 mL) → 부피 단독 기준선 의무화, Cryptogenic 제외 |
| **A2** 데이터 적합성 | Opus | SOOP 특성, 결측, confound | ✅ **부피 특징 1개로 4클래스 macro AUC 0.650** 측정 → 헌장의 "크기 제외 AUC > 0.60" 기준이 학습 없이 통과됨을 폭로(A6 로 이관). 미해결이던 마스크 값 2/3 (10명) 을 **강도 코딩 아티팩트**로 종결(`>0` 이진화 타당). 임상변수 결측 399명이 단일 블록·병변 절반 크기 → MCAR 아님. GE·Siemens 39명 전원 라벨 없음 → 분류 코호트 100 % Philips |
| **A3** 전처리·통계 | Opus | RNG, split, 표시변환 | ✅ **ADC 정규화 버그 발견**: MAD=0 미방어로 **44/1233명(3.6 %)의 ADC 채널 전체가 ±6 포화**(최악 64.4 % 복셀). sub-235 는 ADC 격자가 최대 27 mm 어긋난 채 스택. 증강 RNG 가 워커로 fork 되어 `num_workers>0` 재현 불가(잠복). split 3회·전처리 1,233명 재실행 해시 대조. 테스트 15 → 35 |
| **A4** 모델·최적화 | Opus | 학습 설정, 속도 | ✅ **클립 ±6 이 병변 신호의 절반을 잘라내고 있었다**(병변 TRACE z 중앙값 +6.24, 병변 복셀 50.7 %가 z>6). clip 10 으로 **val Dice 0.5950 → 0.6826**(시드 잡음의 12배). `size` 키를 **어떤 코드도 읽지 않던** 버그 수정. bf16+channels_last 로 1.96배 가속하되 `cudnn.benchmark` 는 재현성 때문에 거부. **Dice +0.010 을 포기하고 ICC 여유를 택해 epochs 40 확정**. 테스트 35 → 42 |
| **A5a** 방법론 교차검증 | **Codex (OpenAI GPT-6)** | 수치·알고리즘 | ✅ **독립 판정 [보류]**. `metrics.py` 전 함수를 NumPy 로 독립 구현해 1e-10 일치(지표 계층 무결). 그러나 [높음] 4건: **RAS 좌우축이 특징·증강에서 뒤바뀜**, **"test 를 읽지 않았다"는 문자 그대로 거짓**(인덱스 생성·A2 부피 재계산), 헌장 v2 는 dev 결과를 본 뒤 개정, 예측마스크 CV 는 전체 파이프라인 OOF 아님(447명 중 367명이 seg-train) |
| **A5b** 방법론 교차검증 | Fable | 수치·알고리즘 (독립), A5a 반박 | ✅ A5a 17건 판정(`docs/agents/A5b_report.md`). 확정: 캐시 좌우축(H)·특징 수정, 증강 축 `flip_axis` 명시, 검출 지표 이원화, 분류 CI·fold·seg-split 보고, test 열람 규칙 재정의 |
| **A6** 목표·진단 설계 | Opus | 성공기준, 로깅, 누수 진단 | ✅ **자기 프로젝트의 성공기준을 스스로 폐기**: `volume_only` 0.6421 로 v1 기준이 무의미함을 재현 → **E1 LAA-vs-CE·E2 부피 대비 증분·E3 SVO 제외 3클래스**로 대체(v1 원문·사유 보존). 통과가 보장된 S1 을 보완할 **S1b 신설**, ICC **CI 병기 의무화**(CI 가 임계값 포함). threshold 스윕 폭 0.0057 → 0.5 고정. **val 실패 사례의 절반은 라벨**(11명이 만성 병변 서명, Dice 0.172 vs 0.713). 테스트 42 → 46 |

## 의도적으로 하지 않은 것 (그리고 그 이유)
| 하지 않은 것 | 이유 |
|---|---|
| **DICOM 입출력 / PACS 연동** | 원본이 NIfTI 다. NIfTI → DICOM 왕복은 "다뤄봤다"는 진술을 만들기 위한 인위적 장치라 A1 의 P0 제안을 Astra 가 반박했고, 범위 밖으로 확정했다 |
| **3D / 2.5D 모델, nnU-Net, 앙상블** | 슬라이스 두께 5 mm · 24~26 슬라이스라 3D 문맥의 이득이 작다고 판단해 P1 로 강등. 2D 한 모델을 끝까지 정직하게 검증하는 쪽을 택했다 |
| **특이도 · PPV** | 이 데이터로는 **계산 자체가 불가능**하다(음성 환자 0명). 정의가 서지 않는 지표를 만들어 보고하지 않는다 |
| **다기관 / 외부 데이터 일반화** | 단일 기관 · Philips 98 % 라 기관 홀드아웃이 성립하지 않는다. 일반화 주장을 하지 않는 쪽을 택했다 |
| **CT 계열(NCCT/CTA/CTP), MLOps, 인허가 문서 모사** | 개인 프로젝트 범위를 넘고, 인허가 문서 흉내는 허위성 오해 소지가 있어 처음부터 제외했다 |

## 빠른 시작 (서버)
```bash
git clone https://github.com/Elechun/JLK-.git && cd JLK-
python -m venv .venv && source .venv/bin/activate && pip install -e .[dev]
bash scripts/run_all.sh          # 다운로드(2.8 GB) → 인덱스 → split → 전처리 → 테스트 → 학습 → 진단 → 분류
```
자세한 순서와 에이전트 실행 방법은 **`docs/01_server_runbook.md`**, 새 Claude Code 채팅에 붙여 넣을 프롬프트는 **`docs/02_handoff_prompt.md`**.

**재현성은 주장이 아니라 실측이다.** 물리적으로 다른 GPU 2장에서 같은 seed·config 로 40 epoch 전체 학습(실측 **279 초**)을 다시 돌려
best epoch·val Dice 가 **소수점 16자리까지 동일**했고 `best.pt` 가 **sha256 바이트 단위로 동일**했다. `data/splits.json` 도 3회 재생성해 해시를 대조했다.
