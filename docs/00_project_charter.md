# 프로젝트 헌장 — DWI 기반 급성 뇌경색 병변 분할 + 병인 분류

## 한 줄 목표
공개 데이터(OpenNeuro SOOP, ds004889)로 제이엘케이 JBS-01K 와 **같은 과제 구조**(DWI → 병변 분할·부피 → 뇌졸중 유형 분류)를
끝까지 한 번 구현·검증해 "비슷한 주제의 유경험자"가 된다. 회사 제품과의 성능 비교·우위 주장은 하지 않는다.

## 범위 (MVP, 서버 1주 기준)
| 포함 | 제외 (명시적으로 하지 않음) |
|---|---|
| 2D U-Net(TRACE+ADC 2채널, 128²) 병변 분할, 환자 단위 3D Dice·부피 일치도 | 3D/nnU-Net 급 대형 모델, 앙상블 |
| 병변 특징 + 임상변수 → 병인(LAA/CE/SVO/Others) 분류 (로지스틱/GBM) | CT 모달리티 확장, PACS 연동, MLOps |
| 환자 단위 split, seed 고정, JSONL 로깅, 진단 스크립트 | 인허가 문서 모사 |
| 에이전트(A1~A6 + Astra) 보고서와 발견 로그 | 임상 사용 주장 |

## 사전 등록 성공 기준 — **v2 (2026-09-09, A6 개정, test 미열람 상태에서 확정)**

> 개정 절차: v1 은 2026-09-08 에 작성됐다. A2 가 "크기 제외 macro AUC > 0.60" 이 GT 부피 특징 **하나**로 이미

> 아래 v2 는 **test 218명의 영상·마스크·라벨을 한 번도 읽지 않은 상태에서** 확정했다.

### A. 분할 (test 218명, `scripts/eval_seg.py --split test` 1회)
| # | 지표 | 기준 | 근거 · 검정력 |
|---|---|---|---|
| **S1** | Dice (GT 병변 보유 환자 평균, 환자 단위 3D) | **≥ 0.55** | v1 유지. 2D 소형 U-Net·128² 조건, 문헌 DWI DSC 0.6~0.8(3D nnU-Net 급)의 보수적 하한. val 0.6855, 부트스트랩 SE 0.019 → 여유 **7.1 SE** [측정]. 미달 시 "실패"로 기록 |
| **S1b** | val→test 일반화 | **\|Dice_test − Dice_val\| ≤ 0.06** | **신설.** S1 은 여유가 7 SE 라 사실상 통과가 보장되어 변별력이 없다. 두 218명 split 차의 SE = 0.019·√2 = 0.027 → 0.06 은 2.2 SE(참 차이가 0일 때 오경보 ≈ 2.7 %) [측정+산술] |
| **S2** | 환자 단위 검출 민감도 (예측 마스크 비어 있지 않음) | **≥ 0.90** | v1 유지. val 0.9725(FN 6/218), 이항 SE 0.011 → 여유 6.5 SE. **특이도는 보고하지 않는다**: 마스크 보유 1,451명 전원 양성, `acuteischaemicstroke` 관측값도 전부 1(A2 F9 독립 확인) |
| **S3** | 부피 일치도 ICC(2,1) | **점추정 ≥ 0.85 이고 95 % 부트스트랩 CI 를 반드시 병기** | 임계값 근거 보강: Koo & Li (2016) 신뢰도 구간(< 0.5 poor / 0.5–0.75 moderate / **0.75–0.90 good** / > 0.90 excellent)의 "good" 구간 상부. val 0.9138, **CI [0.794, 0.990]** → 0.85 가 CI 안에 있으므로 점추정 단독 보고 금지 [측정] |
| **S4** | 부피 오차 | **보고 의무** — MAE(mL), MAPE(%), 중앙값 \|%오차\|, Bland-Altman bias·LoA 를 모두 | v1 강화(A3 이관 1). 병변 부피가 0.067–557 mL 로 4자릿수에 걸쳐 mL 단독 MAE 는 상위 몇 명이 지배 |
| **S5** | 소병변 (<2 mL) | **보고 의무** — Dice **와 함께 검출률·중앙값 \|%오차\|** 를 반드시 병기 | v1 강화(A3 이관 3). 128² 리샘플 후 최소 병변이 **3복셀**이라 1복셀 차이가 Dice 를 0.1 이상 움직인다 → Dice 단독은 해석 불가. 임계값은 두지 않는다(자의적) |
| **S6** | 재현성 | split sha256 = `0f923acd…`, 동일 seed 재실행 val Dice 차이 < 0.02 | v1 유지. `runs/seg_unet2d_repro` 로 **차이 0.000** 확인 [측정] |

### B. 병인 분류 (Cryptogenic 제외 4클래스, mRS·장비·자장세기 입력 금지)
> **v1 기준 "크기 특징 제외 macro AUC > 0.60" 은 삭제한다.** 삭제 사유는 §변경 이력 참조.
> 기본 보고는 **예측 마스크**(배포 형태) 기준이고, GT 마스크(오라클 상한)를 나란히 싣는다.
> test 의 4클래스 라벨 보유자는 **약 79명(추정, 층화 비율에서 산출)** 뿐이라 **모든 AUC 에 95 % 부트스트랩 CI 를 병기**한다.

| # | 지표 | 기준 | 근거 · 검정력 |
|---|---|---|---|
| **E1** (주) | **LAA-vs-CE AUC** (예측 마스크, `full` 세트, `p(LAA)−p(CE)` 를 실제 LAA/CE 환자에서 채점) | 점추정 **> 0.55**. 추가로 CI 하한 > 0.50 이면 **PASS**, 점추정은 넘었으나 CI 가 0.5 를 포함하면 **판정 불가(inconclusive)**, 점추정 ≤ 0.55 면 **FAIL** | 크기 지름길이 가장 약한 축(A2: 크기 특징이 여기서는 +0.027 밖에 못 더함). dev 5-fold CV **0.6551 [0.595, 0.714]** [측정]. test 예상 n≈35 vs 22 → Hanley–McNeil SE 0.073 → 임계 0.55 에서 **검정력 0.93**, 참값이 우연(0.5)일 때 오통과 0.26 [측정+산술] |
| **E2** (주) | **부피 단독 기준선 대비 macro OvR AUC 증분** Δ = macro(`full`) − macro(`volume_only`) | **Δ > 0** (점추정), 짝지은 부트스트랩 CI 병기 | 절대 macro AUC 는 부피 하나로 0.642 가 나오므로 의미가 없고, "부피 위에 무엇을 더 얹었는가"만이 모델의 기여다. dev Δ = **+0.0746 [+0.038, +0.111]**, p(Δ>0)=1.000 [측정]. test n≈79 는 CI 기반 게이트에는 부족하므로 점추정만 게이트로 쓴다 |
| **E3** (보조) | **SVO 제외 3클래스 macro OvR AUC** (LAA/CE/Others, `full`) | **> 0.55** | SVO 는 TOAST 정의상 "<1.5 cm" 이라 라벨 정의가 곧 크기다. SVO 를 빼면 부피 단독은 **0.5125 [0.467, 0.557] = 우연 수준**인데 `full` 은 **0.6551 [0.603, 0.702]** [측정] → 이 차이가 모델의 실질 신호. test SE ≈ 0.060 [추정] → 검정력 ≈ 0.96, 오통과 ≈ 0.20 |
| **E4** | 보고 의무 | 6개 특징 세트(`volume_only`/`full`/`no_size`/`scale_invariant`/`clinical_only`/`size_only`) × {GT, 예측} 마스크의 macro OvR·클래스별 AUC·LAA-vs-CE·balanced accuracy·혼동행렬을 **전부** | 어떤 세트를 골라 보고했는지에 따라 결론이 바뀌지 않도록 |
| **E5** | "크기 특징 제외 세트"의 정의 | **`scale_invariant` 로 재정의** = 차원이 없는 특징 ∧ dev 에서 \|Spearman ρ(log 부피)\| < 0.25 → `largest_component_frac`, `centroid_{x,y,z}_norm`, `age`, `sex_male` | 기존 `no_size` 는 `n_components`(ρ=+0.476)·`NIHSS`(ρ=+0.471)를 남겨 두어 **크기-무관이 아니다** [측정]. `no_size` 는 이전 보고서와의 연속성을 위해 계속 산출하되 "크기 제외"라고 부르지 않는다 |

**해석 규칙(사전 고정)**: SVO 의 높은 AUC 는 모델 성능이 아니라 **라벨 정의(크기)의 재현**이므로,
어떤 문서에서도 "SVO AUC 0.8x" 를 모델의 병인 판별력 근거로 인용하지 않는다.

### 성공 기준 v1 → v2 변경 이력
| v1 원문 | v2 | 변경 사유 (전부 실행해 확인한 수치) |
|---|---|---|
| 병인 분류 macro AUC(OvR), **크기 특징 제외 세트** **> 0.60** | **삭제** → E1·E2·E3 로 대체 | ① GT 병변 **부피 단 하나**의 특징으로 macro OvR AUC = **0.6421**(A6 재현, A2 는 0.650) — 학습 없이 통과하는 기준이라 변별력이 없다. ② `no_size` 세트가 `full` 보다 **높다**(0.7376 vs 0.7301, GT) → "크기 제외"가 크기 제외가 아니다. ③ 크기 신호는 사실상 전부 SVO 에서 온다: SVO 를 빼면 부피 단독 macro 가 0.6421 → **0.5125**(우연) |
| (없음) | **S1b** 신설 | S1 의 val 여유가 7.1 SE 라 통과가 사실상 확정 → 정보가 없는 기준. 일반화 폭을 별도 기준으로 명시 |
| 부피 일치도 ICC(2,1) **≥ 0.85** (근거: "부피는 치료 결정에 쓰이는 출력") | 임계값 유지 + **CI 병기 의무**, 근거를 Koo & Li (2016) 로 교체 | v1 의 근거 문장은 임계값 0.85 를 정당화하지 못했다(왜 0.85 인가에 답이 없음). val ICC 95 % CI 가 **[0.794, 0.990]** 로 임계값을 포함하므로 점추정만 쓰면 과대·과소 판정 위험 [측정] |
| 소병변(<2 mL) **Dice** 별도 보고 | **Dice + 검출률 + 중앙값 %오차** 병기 | 128² 캐시의 최소 병변이 3복셀 → 1복셀 차이가 Dice 를 0.1 이상 움직인다(A3 F13) |
| 부피 오차(MAE, LoA) | + **MAPE·중앙값 %오차** | 부피가 0.067–557 mL, native 복셀 부피도 5.9배 차 → mL 단독은 대형 병변이 지배(A3 이관 1) |
| Dice ≥ 0.55 / 민감도 ≥ 0.90 / 재현성 | **변경 없음** | 근거와 검정력이 충분(각각 7.1 SE·6.5 SE 여유, 재현 실측 차이 0.000) |

### 알려진 한계 (사전 등록 — test 결과와 무관하게 보고서에 남긴다)
1. **홀드아웃이 완전한 blind 가 아니다**: `split.stratum()` 이 `etiology_code` 와 `mask_acute_ml`(<2 mL 구간)을 쓰므로
   **test 의 라벨 메타데이터가 split 경계에 반영**돼 있다. 영상·마스크 복셀은 읽지 않았다 (A3 F9 + A6).
2. 분류 코호트는 **100 % Philips**, 임상변수 결측 425명(병변 크기 중앙값이 절반)이 제외된 낙관적 표본 (A2 F5·F6).
3. 분할 코호트 1,451명은 "숙련 rater 가 그릴 수 있었던 병변"으로 이미 필터링돼 있다 (A2 C8).
4. 음성 환자가 0명이라 **특이도·PPV 는 계산 불가**.

## 선택 확장 (A1 이 P0 로 제안, Astra 가 범위 판정) — MVP 완료 후에만
1. 환자 단위 검출 민감도 보고 → **이미 `metrics.py` 에 포함**. 특이도는 이 데이터로 계산 불가(Astra 반박 수용)

3. DICOM 입출력 → **강등**: 인위적 NIfTI→DICOM 왕복은 가치가 낮음(Astra 반박). README 한 줄로 "제외 이유" 명시
