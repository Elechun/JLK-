# 프로젝트 헌장 — DWI 기반 급성 뇌경색 병변 분할 + 병인 분류

## 한 줄 목표
공개 데이터(OpenNeuro SOOP, ds004889)로 제이엘케이 JBS-01K 와 **같은 과제 구조**(DWI → 병변 분할·부피 → 뇌졸중 유형 분류)를
끝까지 한 번 구현·검증해 "비슷한 주제의 유경험자"가 된다. 회사 제품과의 성능 비교·우위 주장은 하지 않는다.

## 범위 (MVP, 서버 1주 기준)
| 포함 | 제외 (명시적으로 하지 않음) |
|---|---|
| 2D U-Net(TRACE+ADC 2채널, 128²) 병변 분할, 환자 단위 3D Dice·부피 일치도 | 3D/nnU-Net 급 대형 모델, 앙상블 |
| 병변 특징 + 임상변수 → 병인(LAA/CE/SVO/Others) 분류 (로지스틱/GBM) | CT 모달리티 확장, PACS 연동, MLOps |
| 환자 단위 split, seed 고정, JSONL 로깅, 진단 스크립트 | 인허가 문서 모사 |
| 에이전트(A1~A6 + Astra) 보고서와 발견 로그 | 임상 사용 주장 |

## 사전 등록 성공 기준 (테스트셋을 보기 전에 확정, A6 가 검토)
| 지표 (val 기준 모델 선택 → test 1회) | 기준 | 근거 |
|---|---|---|
| Dice (GT 병변 있는 환자 평균, 3D) | ≥ 0.55 | 2D 소형 U-Net·128² 다운샘플 조건. 문헌의 DWI 분할 DSC 는 0.6~0.8(3D nnU-Net 급, ISLES22) 이므로 그 하한을 보수적으로 낮춤. 기준 미달 시 "실패"로 기록 |
| 환자 단위 검출 민감도 (예측 마스크 비어 있지 않음) | ≥ 0.90 | 제품은 "병변 유무" 트리아지 성격이 강함. **특이도는 보고하지 않음**: 마스크 보유 1,451명 전원이 병변 양성이라 음성군이 없음 (Astra 지적) |
| 병변 부피 오차 (MAE, Bland-Altman LoA) | 보고 의무 | JLK-DWI 류 제품의 핵심 출력이 부피. 특이도 대신 이 축으로 제품 언어와 접점 확보 (Astra) |
| 부피 일치도 ICC(2,1) | ≥ 0.85 | 부피는 치료 결정(예: 대형 병변) 에 쓰이는 출력 |
| 소병변(<2 mL) Dice 를 별도 보고 | 보고 의무 | SVO(열공경색)가 가장 어려운 구간, 숨기지 않음 |
| 병인 분류 macro AUC(OvR), **크기 특징 제외 세트** | > 0.60 | SVO 는 정의상 병변 크기 <1.5 cm 이므로 크기 특징 포함 AUC 는 라벨 정의 누수로 부풀 수 있음(Astra 확인: SVO 중앙값 1.13 mL vs 타군 10~23 mL). 두 세트 + **부피 단독 기준선** + **LAA-vs-CE AUC** 를 나란히 보고. **Cryptogenic(원인불명) 은 제외**, mRS 는 입력에 쓰지 않음(퇴원 결과 → 누수) |
| 재현성 | split sha256 동일, seed 고정 재실행 시 val Dice 차이 < 0.02 | CLAUDE.md 규칙 |

## 선택 확장 (A1 이 P0 로 제안, Astra 가 범위 판정) — MVP 완료 후에만
1. 환자 단위 검출 민감도 보고 → **이미 `metrics.py` 에 포함**. 특이도는 이 데이터로 계산 불가(Astra 반박 수용)
2. 2.5D 입력(인접 3슬라이스 스택) 변형 1개 → P1, 시간이 남을 때만 (Astra 부분동의)
3. DICOM 입출력 → **강등**: 인위적 NIfTI→DICOM 왕복은 가치가 낮음(Astra 반박). README 한 줄로 "제외 이유" 명시

## 데이터
- OpenNeuro ds004889 (SOOP), CC0. 1,715명 영상, 1,451명 급성 병변 마스크(빈 마스크 0명), 병인 라벨 594명(LAA 262/CE 159/SVO 101/OtherDet 72) + Cryptogenic 486.
- 장비: Philips 1,676 / GE 20 / Siemens 19, 1.5T 1,357 / 3T 358, 슬라이스 두께 5 mm(6 mm 간격), 인플레인 224~432.
- 인덱스: `python scripts/build_index.py` → `data/index.csv`, `data/index_summary.json`.
