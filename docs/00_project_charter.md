# 프로젝트 헌장 — DWI 기반 급성 뇌경색 병변 분할 + 병인 분류

## 한 줄 목표
공개 데이터(OpenNeuro SOOP, ds004889)로 제이엘케이 JBS-01K 와 **같은 과제 구조**(DWI → 병변 분할·부피 → 뇌졸중 유형 분류)를
끝까지 한 번 구현·검증해 "비슷한 주제의 유경험자"가 된다. 회사 제품과의 성능 비교·우위 주장은 하지 않는다.

## 범위 (MVP, 서버 1주 기준)
| 포함 | 제외 (명시적으로 하지 않음) |
|---|---|
| 2D U-Net(TRACE+ADC 2채널, 128²) 병변 분할, 환자 단위 3D Dice·부피 일치도 | 3D/nnU-Net 급 대형 모델, 앙상블 |
| 병변 특징 + 임상변수 → 병인(LAA/CE/SVO/Others) 분류 (로지스틱/GBM) | CT 모달리티 확장, PACS 연동, MLOps |
| 환자 단위 split, seed 고정, JSONL 로깅, 진단 스크립트 | 인허가 문서 모사 |
| 에이전트(A1~A6 + Astra) 보고서와 발견 로그 | 임상 사용 주장 |

### B. 병인 분류 (Cryptogenic 제외 4클래스, mRS·장비·자장세기 입력 금지)
> **v1 기준 "크기 특징 제외 macro AUC > 0.60" 은 삭제한다.** 삭제 사유는 §변경 이력 참조.
> 기본 보고는 **예측 마스크**(배포 형태) 기준이고, GT 마스크(오라클 입력 참조 — 성능 상한이 아님, A5a 지적 11)를 나란히 싣는다.
> test 의 4클래스 라벨 보유자는 **약 79명(추정, 층화 비율에서 산출)** 뿐이라 **모든 AUC 에 95 % 부트스트랩 CI 를 병기**한다.

| # | 지표 | 기준 | 근거 · 검정력 |
|---|---|---|---|
| **E1** (주) | **LAA-vs-CE AUC** (예측 마스크, `full` 세트, `p(LAA)−p(CE)` 를 실제 LAA/CE 환자에서 채점) | 점추정 **> 0.55**. 추가로 CI 하한 > 0.50 이면 **PASS**, 점추정은 넘었으나 CI 가 0.5 를 포함하면 **판정 불가(inconclusive)**, 점추정 ≤ 0.55 면 **FAIL** | 크기 지름길이 가장 약한 축(A2: 크기 특징이 여기서는 +0.027 밖에 못 더함). dev 5-fold CV(pooled OOF) A6 시점 0.6551 [0.595, 0.714] → **좌우축 수정 후 0.6709 [0.611, 0.730]** [측정, A5b]. test 예상 n≈35 vs 22 → Hanley–McNeil SE 0.073. **검정력 정정(A5a 지적 5, A5b 시뮬레이션)**: "0.93" 은 점추정 게이트 P(AUC_hat > 0.55) 이고, **실제 PASS 규칙(CI 하한 > 0.5 포함)의 통과 확률은 참값 0.655 에서 0.54(판정불가 0.40, FAIL 0.06)**, 참값 0.5 에서 PASS 0.017·판정불가 0.25 [측정: `scripts/analysis/a5b_e1_power.py`, 300회 × 2,000 부트스트랩]. 0.55 는 두 오류를 "동시에 최소화"하는 값이 아니라 A6 가 고른 절충값이다(오류 합은 0.575 근처가 더 작다 — A5a). **종합 판정 규칙**: 병인 파트는 E1·E2·E3 를 각각 보고하고, 하나라도 판정불가면 "판정불가", FAIL 이 있으면 "실패"로 요약한다 |
| **E2** (주) | **부피 단독 기준선 대비 macro OvR AUC 증분** Δ = macro(`full`) − macro(`volume_only`) | **Δ > 0** (점추정), 짝지은 부트스트랩 CI 병기 | 절대 macro AUC 는 부피 하나의 로지스틱 기준선으로 0.642 가 나오므로 의미가 없고, "부피 위에 무엇을 더 얹었는가"만이 모델의 기여다. dev Δ = +0.0746 [+0.038, +0.111] (A6) → 좌우축 수정 후 **+0.0752 [+0.039, +0.110]** [측정, A5b]. `p(Δ>0)` 는 재표본 중 양의 비율이지 사후확률·p값이 아니다(A5a 지적 5). test n≈80 은 CI 기반 게이트에는 부족하므로 점추정만 게이트로 쓴다 |
| **E3** (보조) | **SVO 제외 3클래스 macro OvR AUC** (LAA/CE/Others, `full`; SVO 를 뺀 dev 로 **재적합**한 3클래스 분류기) | **> 0.55** | SVO 는 TOAST 정의상 "<1.5 cm" 이라 라벨 정의가 곧 크기다. | **E4** | 보고 의무 | 6개 특징 세트(`volume_only`/`full`/`no_size`/`scale_invariant`/`clinical_only`/`size_only`) × {GT, 예측} 마스크의 macro OvR·클래스별 AUC·LAA-vs-CE·balanced accuracy·혼동행렬을 **전부**, **모든 AUC(클래스별·3클래스 포함)에 95 % 부트스트랩 CI**, pooled OOF 와 fold 별 AUC 병기, OOF 확률·ID sidecar(`results/cls_*.oof.json`) 보존(A5a 지적 6·8, A5b 구현). | **E5** | "크기 특징 제외 세트"의 정의 | **`scale_invariant` 로 재정의** = 병변 기하와 물리 단위를 공유하지 않는 특징(무차원 비율·정규화 좌표) **또는** 임상 공변량(age 는 "년" 단위라 문자 그대로 무차원은 아니다 — A5a 지적 10) ∧ **GT dev** 에서 \|Spearman ρ(log 부피)\| < 0.25 → `largest_component_frac`, `centroid_{x,y,z}_norm`, `age`, `sex_male`. 세트는 고정하며, 예측 마스크에서는 `centroid_z_norm` ρ = 0.264 로 기준을 살짝 넘는다는 사실을 병기한다 [측정]. 좌우축 수정(A5b)으로 `centroid_x` 는 좌우, `centroid_y` 는 전후 좌표가 됐다(값은 이름만 교환, 세트 결과 불변) | 기존 `no_size` 는 `n_components`(ρ=+0.476)·`NIHSS`(ρ=+0.471)를 남겨 두어 **크기-무관이 아니다** [측정]. `no_size` 는 이전 보고서와의 연속성을 위해 계속 산출하되 "크기 제외"라고 부르지 않는다 |

**해석 규칙(사전 고정)**: SVO 의 높은 AUC 는 모델 성능이 아니라 **라벨 정의(크기)의 재현**이므로,
어떤 문서에서도 "SVO AUC 0.8x" 를 모델의 병인 판별력 근거로 인용하지 않는다.

| 병인 분류 macro AUC(OvR), **크기 특징 제외 세트** **> 0.60** | **삭제** → E1·E2·E3 로 대체 (단, `no_size` 의 test 결과로 v1 판정도 병기) | ① GT 병변 **부피 단 하나**를 입력한 로지스틱 기준선으로 macro OvR AUC = **0.6421**(A6 재현, A2 는 0.650) — 1-특징 기준선이 넘는 기준이라 변별력이 없다("학습 없이"는 부정확 — A5a 지적 11). ② `no_size` 세트가 `full` 보다 **높다**(0.7376 vs 0.7301, GT) → "크기 제외"가 크기 제외가 아니다. ③ 크기 신호는 대부분 SVO 에서 온다: SVO 를 빼면 부피 단독 macro 가 0.6421 → **0.5125**(CI 가 0.5 포함; LAA-vs-CE 축에는 0.596 의 잔여 신호가 남으므로 "완전 소멸"은 아니다) |
| (없음) | **S1b** 신설 | S1 의 val 여유가 7.1 SE 라 통과가 사실상 확정 → 정보가 없는 기준. 일반화 폭을 별도 기준으로 명시 |
| 부피 일치도 ICC(2,1) **≥ 0.85** (근거: "부피는 치료 결정에 쓰이는 출력") | 임계값 유지 + **CI 병기 의무**, 근거를 Koo & Li (2016) 로 교체 | v1 의 근거 문장은 임계값 0.85 를 정당화하지 못했다(왜 0.85 인가에 답이 없음). val ICC 95 % CI 가 **[0.794, 0.990]** 로 임계값을 포함하므로 점추정만 쓰면 과대·과소 판정 위험 [측정] |
| 소병변(<2 mL) **Dice** 별도 보고 | **Dice + 검출률 + 중앙값 %오차** 병기 | 128² 캐시의 최소 병변이 3복셀 → 1복셀 차이가 Dice 를 0.1 이상 움직인다(A3 F13) |
| 부피 오차(MAE, LoA) | + **MAPE·중앙값 %오차** | 부피가 0.067–557 mL, native 복셀 부피도 5.9배 차 → mL 단독은 대형 병변이 지배(A3 이관 1) |
| Dice ≥ 0.55 / 민감도 ≥ 0.90 / 재현성 | **변경 없음** | 근거와 검정력이 충분(각각 7.1 SE·6.5 SE 여유, 재현 실측 차이 0.000) |

### 알려진 한계 (사전 등록 — test 결과와 무관하게 보고서에 남긴다)
1. **홀드아웃이 완전한 blind 가 아니다**: `split.stratum()` 이 `etiology_code` 와 `mask_acute_ml`(<2 mL 구간)을 쓰므로
   **test 의 라벨 메타데이터가 split 경계에 반영**돼 있다 (A3 F9 + A6). **정정(A5a 지적 2, A5b 확정)**: "영상·마스크 복셀은 읽지 않았다"는
   문자 그대로는 거짓이다. (a) `build_index.py` 는 층화 split 에 필요한 부피·성분수·적격성을 얻기 위해 **전 코호트 급성 마스크 복셀을 읽는다**
   (인덱스 없이는 층화 split 자체가 불가능한 부트스트랩 관계); (b) split 확정 뒤 A2 의 `a2_volumes.py`(02:55 KST) 가 1,451명 전원의 마스크
   부피를 다시 계산했고 A2 보고서의 전체 코호트 기술통계에 쓰였다. 두 경우 모두 **영상 강도는 읽지 않았고**, test 의 어떤 값도 학습·모델 선택·
   threshold·특징 세트 선정·지표 계산에 들어가지 않았다(runs/results/cache 전수 검사, A5a·A5b). 따라서 정확한 표현은
   **"부피·라벨 메타데이터에는 노출됐으나 모델 성능 평가에는 쓰인 흔적이 없는 홀드아웃"** 이다. `a2_volumes.py` 는 이제 기본값이
   train+val 이며, 회귀 테스트가 split 필터 없는 전 코호트 마스크 판독 스크립트를 금지한다.
2. 분류 코호트는 **100 % Philips**, 임상변수 결측 425명(병변 크기 중앙값이 절반)이 제외된 낙관적 표본 (A2 F5·F6).
3. 분할 코호트 1,451명은 "숙련 rater 가 그릴 수 있었던 병변"으로 이미 필터링돼 있다 (A2 C8).
4. 음성 환자가 0명이라 **특이도는 계산 불가**이고, 표본 내 PPV 는 FP 가 구조적으로 0 이라 자명하게 1 이다(임상 PPV 를 추정할 자료가 없다는
   것이 정확한 한계 — A5a 지적 13). 환자 단위 "검출"은 비어 있지 않은 출력률이므로 병변 접촉률(S2)을 함께 읽어야 한다.
5. **캐시 좌우축 (A5a 지적 3, A5b 확정)**: 캐시는 `(S, H, W)` 이고 **H 가 좌우(RAS x), W 가 전후(RAS y)** 다. 2026-09-09 이전 `features.py` 는
   W 를 좌우로 읽어 `laterality_left_frac`·`bilateral` 이 전후 분율이었고 x/y 좌표 이름이 바뀌어 있었다(수정 완료, 위 dev 수치는 수정 후 값).
   `runs/seg_unet2d` 의 증강 "left-right flip" 은 실제로 **전후(A-P) 반전**이었다 — 처리 방침은 §C 참조.
6. **예측 마스크 기반 dev CV 는 분류 단계 CV 다 (A5a 지적 4)**: 분류 코호트 447명 중 367명은 분할 모델의 train 이라 그 예측 마스크는 배포 시보다
   깨끗하다(A5b 측정: Dice 0.758 vs val 부분 0.706, log 부피 MAE 0.20 vs 0.33). 다만 pooled OOF AUC 를 두 부분으로 나눠 보면 `full` macro
   0.717(seg-train) vs 0.720(seg-val) 으로 낙관 편향이 검출되지 않았고 GT 마스크 대조군도 같은 패턴이다. test 는 단일 분할 모델의 정직한
   예측을 쓰므로 test 판정 자체는 이 문제의 영향을 받지 않는다(분류기가 더 깨끗한 특징으로 학습된 것은 test 에 보수적으로 작용).

## 선택 확장 (A1 이 P0 로 제안, Astra 가 범위 판정) — MVP 완료 후에만
1. 환자 단위 검출 민감도 보고 → **이미 `metrics.py` 에 포함**. 특이도는 이 데이터로 계산 불가(Astra 반박 수용)
2. 2.5D 입력(인접 3슬라이스 스택) 변형 1개 → P1, 시간이 남을 때만 (Astra 부분동의)
3. DICOM 입출력 → **강등**: 인위적 NIfTI→DICOM 왕복은 가치가 낮음(Astra 반박). README 한 줄로 "제외 이유" 명시
