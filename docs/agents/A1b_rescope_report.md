### 5-1. "전주기(응급실 → 재활)"가 뜻하는 파이프라인 단계

제품 원문 + 예후 연구를 합치면 단계가 이렇게 확정된다:

```
[응급실 선별]   JLK-ICH(NCCT 출혈 배제) → JLK-LVO(CTA 대혈관폐색)
      ↓
[치료 방침]     JLK-CTP / JLK-PWI (코어·반음영 부피 → 재개통 시술 판단)
      ↓
[진단·원인규명] JBS-01K (DWI 병변 검출·크기/위치/패턴 → LAA/CE/SVO 유형 확률)   ← 본 프로젝트가 서 있던 자리
      ↓
[예후·2차예방]  ★ 기능결과 예측 / END 예측 / 재발 위험 / 숨은 심방세동  ← 제품 없음, 연구 단계
      ↓
[재활]          상지 운동기능 예후 예측(JKMS), 퇴원 후 웨어러블 모니터링
```

> **가장 중요한 발견**: 본 프로젝트는 위 4단계 중 **3단계(진단·원인규명)** 에 있었고, 그 단계는 **JBS-01K 라는 완제품이 이미 있는 자리**다. 반면 **4단계(예후)는 JLK 가 논문·MOU 로 밀고 있으나 제품이 없는 자리**다. 지원자 관점에서 **비어 있는 칸을 채우는 쪽이 3단계 재현보다 차별성이 크다.**

### 5-2. 멀티모달(영상+임상변수) 결합을 실제로 하는가 → **한다**
- JKMS 연구: **MRI + 임상정보**, 그리고 "**영상 추가가 임상정보 단독보다 낫다**"를 명시적으로 보였다 **[원문]**. 이것은 본 프로젝트가 재현할 수 있는 **정확히 같은 형태의 주장**이다.
- 뇌·심장 연계: 영상 + **EMR** + 생체신호. **[원문]**

### 5-3. 선행연구 벤치마크 (JLK 소속은 아니지만 과제가 거의 동일) **[원문]**
"Multi-modality multi-task model for mRS prediction using diffusion-weighted resonance imaging" (Park & Kim 외, 강원대·한림대·춘천성심병원, PMC11374799)
- nnU-Net 기반 **DWI 병변 분할 + mRS 예측 멀티태스크**
- 임상변수: 성별, 나이, BMI, NIHSS, **TOAST**, 고혈압, 당뇨, 고지혈증, 흡연, 심방세동, 혈당, 혈압
- **Dice 0.7375 (test)**, **AUC 0.8080 (test, DWI+NIHSS+임상)**
- 타깃: **3개월** mRS, **0–2 양호 / 3–6 불량**
→ 본 프로젝트 제안(A)의 **방법론적 정당성과 성능 눈금**을 그대로 제공한다. 우리 파일럿(AUC 0.803, 퇴원 mRS)은 이 눈금과 같은 자릿수다.

### 6-5. 파일럿 예측 실험 — **train+val 538명, 5-fold CV, test 미사용**

기존 자산만 사용: `runs/seg_unet2d/pred_masks/` (1,451명 전원 존재) + `src/strokeai/features.py`(15개 병변 특징) + participants.tsv 임상변수.
타깃: mRS ≥ 3 (불량 기능결과). 모델: 로지스틱 회귀(표준화+결측대치).

| 특징 조합 | 5-fold CV AUC |
|---|---|
| 임상변수만 (age, NIHSS, priorstroke) | 0.772 ± 0.034 |
| 병변 15특징만 (예측 마스크) | 0.712 ± 0.035 |
| 병변 부피(log)만 | 0.741 ± 0.020 |
| **임상 + 병변부피(log)** | **0.803** |
| 임상 + 병변 15특징 전부 | 0.788 ± 0.050 |
| (GB) 임상 + 병변 15특징 | 0.821 |

**Fold 단위 대응비교 (가장 중요):**

| 조합 | fold별 AUC | 평균 | 임상단독 대비 개선 fold 수 |
|---|---|---:|---:|
| 임상 단독 | 0.787 / 0.711 / 0.804 / 0.797 / 0.760 | 0.772 | — |
| **임상 + 병변부피** | 0.836 / 0.751 / 0.808 / 0.820 / 0.799 | **0.803** | **5 / 5** |
| 임상 + 15특징 | 0.823 / 0.692 / 0.792 / 0.833 / 0.800 | 0.788 | 3 / 5 |

순서형(ordinal) mRS 회귀(Ridge, OOF): 임상 단독 Spearman 0.503 / MAE 1.29 → **임상+병변특징 Spearman 0.556 / MAE 1.21**.

> **판정: 후보 A 는 데이터로 지지된다.**
> 병인 분류(Astra R7)에서는 병변 특징이 부피 단독 기준선에 **밀렸다**. 예후 예측에서는 반대로 **영상이 임상변수 위에 일관되게(5/5 fold) 값을 더한다.** 이것이 주제 전환의 가장 강한 근거다.
> **동시에 정직한 단서**: 이득 폭은 +0.031 AUC로 **작다**. 15특징 전체를 넣으면 오히려 불안정(3/5)해진다 → **간결한 모델(임상 + log 부피, 필요시 +다발성)** 이 정답이며, 이를 "특징을 늘려도 안 좋아진다"는 **음성 결과로 함께 보고**하는 것이 회사가 요구하는 "임상적 근거 창출" 태도에 맞는다.

### 6-6. 대안 후보용 데이터 실측
- 만성 병변 마스크: eligible 중 **198명뿐**(train+val 168, mRS 동시보유 **65명**) → 별도 주제로는 표본 부족.
- 스캐너 분포: Philips 1,427 / GE 16 / Siemens 8 → **벤더 일반화 실험 불가**(GE·Siemens 합쳐 24명).
- 자장 세기: **1.5T 1,154 / 3.0T 297** → **자장 세기 도메인 시프트 실험은 가능**(단 3.0T 297명).
- 시계열(추적 영상) 없음 → **병변 성장·END 예측 재현 불가**.

**1순위 = A (예후 예측)** — 유일하게 (a)~(e) 전부를 통과한다.
**보조로 D 를 A 의 한 개 장(章)으로 편입** (예후 모델의 부피 입력이 자장 세기에 얼마나 흔들리는가 = 실무적으로 의미 있는 안정성 검증).
**2순위 = G (3D 분할)** — A 를 끝낸 뒤 시간이 남으면. 제품 스펙 정합성은 최고지만 새 학습 비용이 크고 결론이 예측 가능하다.

### A 를 1순위로 추천하는 이유 (3줄)
1. **회사가 제품으로는 아직 못 채운 칸이다.** 검출·분할·유형분류는 JBS-01K 가 이미 있다. 예후는 JLK 가 논문·MOU 로 밀고 있으나 **인허가 제품이 없는 자리**이고, 공고 업무의 "**상용화 제품에 대한 연구지원 및 임상적 근거 창출**"이 정확히 그 일이다.
2. **기존 프로젝트의 실패를 자산으로 바꾼다.** "병인 분류에서 누수라 뺐던 mRS 를, 예측 타깃으로 옮기면 정당해진다"는 전환은 **데이터 누수를 이해하고 있다는 증거**로 읽힌다. 완료된 분할 모델(Dice 0.688, ICC 0.984)이 폐기되지 않고 **특징 추출기로 재사용**된다.
3. **데이터가 실제로 받쳐준다.** 병인 분류와 달리 영상이 임상변수 위에 **5/5 fold 일관되게** 값을 더한다(0.772→0.803). 즉 이번엔 **양성 결과로 끝낼 수 있다.**

### 8-4. 성공 기준 (사전 선언)
- **주 기준**: 임상+부피 모델의 CV AUC 가 임상 단독보다 **fold 다수(≥4/5)에서 높고**, 부트스트랩 ΔAUC 95% CI 하한 > 0.
  - 파일럿 결과 **5/5 fold 개선, +0.031** → 통과 전망. 단 ΔAUC CI 는 반드시 계산할 것(이득이 작아 0 을 걸칠 수 있다).
- **보조 기준**: 절대 AUC ≥ 0.78, 보정 기울기 0.8–1.2.
- **음성이어도 보고**: 15특징 확장이 성능을 떨어뜨린다는 것(3/5)은 그대로 싣는다.

### 8-5. **오케스트레이터 결정이 필요한 지점 — test 218**
현 규칙은 "test 218명으로 새 모델을 평가하지 마라"다. 그런데 test 중 mRS 보유자는 **82명**뿐이다. 선택지:
- **(권장) 옵션 1** — test 를 건드리지 않고 **train+val 538명 중첩 CV(nested CV)** 로만 보고. 정직하고 규칙 위반 없음. 한계: "완전 미사용 홀드아웃 없음"을 명시.
- **옵션 2** — 82명에 대해 **단 1회** 최종 평가. 통계력이 약해(n=82, 사건 ~40) AUC CI 폭 ±0.10 수준. **권장하지 않음.**
- **옵션 3** — mRS 기준으로 새 split 을 만든다. **반대**: 기존 분할 모델이 train 에서 학습됐으므로 분할 학습 train 을 예후 test 로 쓰면 낙관 편향이 생긴다.
→ **옵션 1 을 권고**한다.

### 8-7. 기존 프로젝트와의 서술 통합 (README 포지셔닝 제안)
주제를 "바꾼다"가 아니라 **"파이프라인을 한 단계 더 밀었다"** 로 쓴다:

> DWI 분할(Dice 0.688, ICC 0.984) → **① 병인 분류 = 음성 결과**(부피 단독 기준선을 못 넘음, 판정 불가) → **② 예후 예측 = 양성 결과**(영상이 임상변수 위에 5/5 fold 값을 더함).
