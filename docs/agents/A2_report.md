4. 단순 규칙 "부피 < 1.77 mL → SVO" 만으로 SVO recall 0.648 / precision 0.434,

| 특징 | ρ vs log부피 |
|---|---:|
| 최대 성분 부피(log) | +0.981 |
| 병변이 걸친 슬라이스 수 | +0.881 |
| 최대 확장(mm) | +0.805 |
| **연결성분 수 (ncomp)** | **+0.443** |
| **NIHSS** | **+0.472** (eligible train+val 전체 n=806 에서도 +0.485) |
| 최대성분/전체 부피 비 | −0.111 |
| 나이 | −0.094 |

→ 성분 수는 "형태 특징"이 아니라 사실상 크기 대리변수이고, **NIHSS(임상변수)조차 부피의 대리변수**다.
따라서 "크기 특징 제외 세트"라 부를 수 있는 것은 `최대성분/전체 부피 비`, `슬라이스 밀도` 정도뿐이며,
NIHSS 를 넣는 순간 크기 경로는 완전히 차단되지 않는다. 보고 시 이 사실을 명시해야 한다.

## 5. Confound (b) — 장비·자장세기·해상도 [심각도: 중간] [확인]

`--section scanner`, eligible 1,451.

**병인 × 장비**

| 병인 | GE | Philips | Siemens |
|---|---:|---:|---:|
| CE / Cryptogenic / LAA / OtherDet / SVO | 0 | 149 / 403 / 232 / 62 / 84 | 0 |
| tsv `n/a` | 15 | 316 | 6 |
| tsv 미등재 | 1 | 181 | 2 |

χ² p = 1.3e-8. 전체 코호트로 보면 **GE 20명·Siemens 19명 전원이 병인 라벨이 없다**
(GE: 미등재 2 + n/a 18, Siemens: 미등재 2 + n/a 17) [확인].
→ **F6: 병인 분류 코호트(4클래스 527 + Cryptogenic 403)는 100 % Philips**. 분류 과제에서 장비는 상수이므로
장비 confound 는 없지만, **장비 일반화 주장도 원천적으로 불가능**하다. 반대로 분할 코호트에는 GE 16 + Siemens 8 = 24명이
섞여 있고 이들은 임상 메타데이터가 없다.

**병인 × 자장세기** (3T 비율): OtherDet 0.355 · SVO 0.238 · Cryptogenic 0.221 · CE 0.195 · LAA 0.185 · `n/a` 0.145.
4클래스만의 χ² p = 0.030 → 약하지만 유의. **OtherDet 의 3T 편중(35.5 % vs LAA 18.5 %)이 유일하게 눈에 띄는 축**이며,
OtherDet(n=62)은 최소 클래스라 **자장세기가 OtherDet 예측의 지름길이 될 수 있다** [추정].

**자장세기 ↔ 병변 부피**: 1.5T 중앙값 7.91 mL vs 3.0T 13.35 mL, Mann-Whitney p = 0.029,
자장세기의 부피 예측 AUC = 0.459(=0.541 방향 무시) → **효과는 통계적으로만 유의하고 실질적으로 작다** [확인].

**인플레인 해상도 ↔ 부피**: Spearman ρ = −0.064 (p = 0.014) — 무시 가능 [확인].
단 해상도는 자장세기와 강하게 얽혀 있다(3T 인플레인 중앙값 0.599 mm vs 1.5T 1.022 mm) [확인].
병인별 인플레인 해상도 차이는 없음(Kruskal p = 0.32).
장비 모델별 자장은 결정론적이다: Ingenia Ambition X = 전부 1.5T(796), Ingenia Elition X = 전부 3T(176),
Achieva 만 혼재(1.5T 245 / 3T 121) → **모델명은 자장세기의 거의 완전한 대리변수** [확인].

**누적 시점 효과 없음**: subject_num 10분위별 3T 비율 0.186~0.262, 병변 중앙값 3.8~13.7 mL 로 뚜렷한 추세 없음 [확인].

   장비/프로토콜 원인은 배제된다 [확인].
3. **DWI 신호 특성이 정상 마스크와 동일**하다 [확인]. 마스크 내부/외부 평균비 —

   무작위 정상 40명(seed 2026): TRACE 3.521배(40/40), ADC 0.785배(31/40).

4. **문서 근거 없음** [확인]. `derivatives/lesion_masks` 아래에 `dataset_description.json`·README·JSON 사이드카가
   **0개**이고, `data/raw/ds004889/README.md` 와 `CHANGES` 는 마스크 값에 대해 한 글자도 기술하지 않는다

   `participants.json` 에도 마스크 관련 항목이 없다. → 값 2/3 에 부여된 공식 의미는 **존재하지 않는다**.
5. **결합 마스크(`desc-lesion_mask`)의 인코딩 자체가 일관되지 않다** [확인].
   값 2/3 환자 9명은 결합 마스크가 급성 마스크와 동일한 값(2 또는 3)을 그대로 가진다.

   결합은 {1: 8,706, 4: 199} 로 **합집합=1, 교집합=4** 라는 또 다른 임의 코딩을 쓴다.
   정상 환자(예: sub-1: 급성 1 / 만성 1 / 결합 1)와 비교하면 결합 파일은 값 의미가 통일돼 있지 않다.

### 7-3. 판정

   공개 포트폴리오 프로젝트에 CC0 는 명확한 이점 [확인].
3. **규모**: 급성 마스크 1,451명은 ISLES'22(250)의 5.8배, ISLES'24(149)의 9.7배 [확인].
4. **임상변수 동반**: age/sex/NIHSS/priorstroke/acuteischaemicstroke 가 4클래스 코호트 527명에 대해 **결측 0 %**(race 7.0 %, bmi 4.9 %, mRS 33.8 %) [확인].

## 11. 후속 에이전트 인계 (A3 전처리 / A6 목표·진단)

**A3 preprocessing-stats**
1. `(mk > 0)` 이진화 유지 — A2 판정 [타당]. 전처리 로그에 "값 2/3 마스크 10명" 건수를 기록할 것.
2. 결합 마스크 `*_desc-lesion_mask.nii.gz` 는 **사용 금지**(값 인코딩 비일관, sub-507 은 {1,4}).
3. `acute == chronic` 인 환자(train+val 확인 3명, 급성이 만성에 완전 포함 5명) 검사를 1,451명 전체에 돌려 플래그 컬럼 추가.
4. 128² 리샘플은 병변을 지우지 않음(빈 마스크 0, 부피 보존 0.990) — 재확인만 하면 됨. 최소 병변 3복셀은 별도 기록.
5. 부피 양자화: 복셀 부피가 1.45~8.61 mm³ 로 6배 차 → 부피 오차 보고는 mL 와 % 둘 다.
6. `acuteischaemicstroke` 는 상수(값 1뿐) → 특징에서 제외.

**A6 goals-diagnostics**
1. **헌장 성공기준 재검토 필요[높음]**: "병인 macro AUC(크기 제외) > 0.60" 은 **GT 부피 한 개로 0.650** 이 나오므로 변별력이 없다.
   대안: ① **부피 단독 기준선 대비 증분**(현재 상한 +0.075), ② **LAA-vs-CE AUC**(부피 증분 +0.027), ③ SVO 제외 3클래스 macro.
2. "크기 특징 제외 세트" 정의를 스케일 불변 특징으로 재작성하고, NIHSS 포함 시 크기 경로가 남는다는 점을 각주로 고정.
3. 특이도 미보고 방침 유지 — `acuteischaemicstroke` 에 0 값이 한 건도 없음을 A2 가 독립 확인.
4. 누수 진단 스크립트에 추가할 항목: (a) 예측 부피만으로 병인 AUC 재계산, (b) 자장세기/장비만으로 병인 AUC 계산
   (0.5 에서 유의하게 벗어나면 프로토콜 누수), (c) train/val 간 병변 부피 분포 비교(현재 <1 mL 비율 train 0.171 / val 0.156 — 균형 양호).
5. 분류 보고에는 반드시 "제외된 425명은 병변이 절반 크기" 한계 문장을 포함.

## 12. 한계 (A2 스스로의)

- 병인 라벨(TOAST)의 **정확성 자체는 검증 불가**하다. 원 논문·판정 프로토콜 원문을 확인하지 않았고, tsv 값만 신뢰했다.
- 병변 "최대 확장"은 축 정렬 바운딩박스 기준이라 실제 최대 직경을 과대평가한다 [추정]. TOAST 1.5 cm 기준과의 비교는 참고치다.
- 연결성분 수는 `scipy.ndimage.label` 기본 6-이웃 기준이라 성분이 과다계수될 수 있다 [추정].
- 4~5절의 AUC 는 **GT 마스크** 기반 상한이다. 실제 파이프라인은 예측 마스크를 쓰므로 값이 더 낮게 나올 것이다 [추정].
- CQ500·RSNA·BHSD 는 검증하지 않았다(접근 실패 또는 미조사). Astra 표기를 그대로 두었다.
- test 218명에 대한 개별 조사·전용 통계는 수행하지 않았다.
