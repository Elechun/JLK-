## 0. 요약 판정

**판정: [소병변은 개선할 수 있다. 다만 이유가 통념과 다르다.**
**이 구간의 손실은 "덜 그린 것"이 아니라 "아예 못 찾은 7명"이고(측정 §3.2), 그래서 문맥(H4)도 FN 가중(H5 Tversky)도**
**전혀 듣지 않았다 — FN 가중은 오히려 과대분할만 늘려 Dice 를 깎았다. 실제로 들은 것은 아무도 보지 않았던**
**"슬라이스 샘플러의 크기 편향"이다: <2 mL 환자는 코호트의 28 %인데 학습 슬라이스의 10 %만 받고 있었고,**
**환자 병변 부피의 −0.5 제곱으로 재표집하자 못 찾던 3명을 찾으면서 소병변·전체 Dice·ICC 가 함께 올랐다.]**

| # | 가설 | 판정 (사전 등록 3시드 규칙) | 소병변 Δ | 순이득? |
|---|---|---|---|---|
| H1 | 해상도 192² | **효과 없음** (기존 확정 결과 인용) | −0.008 | 아니오 |

## 2. 실험 규약과 **사전 확정한 판정 기준**

판정 기준은 **어떤 variant 도 학습을 마치기 전에** 확정했고, 그대로 `scripts/analysis/small_lesion_report.py`
의 docstring 과 코드에 박아 두었다.

| 항목 | 값 |
|---|---|
| 기준선 | `configs/seg_unet2d.yaml` 현재 값 그대로 (40 epoch, size 128, clip 10, flip_axis ap, batch 64, lr 1e-3) |
| 기준선 run | **재학습하지 않음** — `runs/a5b_flip_ap_s{2026,7,77}` 이 이미 이 config·이 시드다 (`config.json` 이 yaml 과 완전 일치함을 확인 [측정]). 시드 잡음 추정을 위해 seed 123·777 을 **추가 학습** |
| variant 조건 | 기준선 config 에서 **해당 키 그룹만** 덮어씀. epoch·시드·batch·lr·캐시 전부 동일 |
| 시드 | 2026 / 7 / 77 (기준선과 동일한 3개) |
| 주 지표 | val Dice, GT 부피 `[0,2)` mL 구간 (n = 60) |
| **판정 임계** | `효과 = mean(variant, 3시드) − mean(기준선, 3시드)` 가 **기준선 소병변 Dice 의 시드 SD 의 2배 이상**일 것 |
| 순이득 가드레일 1 | 전체 val Dice 평균이 기준선 − **0.007** (A4 가 측정한 전체 Dice 시드 폭) 이상 |
| 순이득 가드레일 2 | 부피 ICC(2,1) 평균이 기준선 − 2 × (기준선 ICC 시드 SD) 이상 |
| 결과 라벨 | 임계 통과 + 가드레일 통과 → **효과 있음(순이득)** / 임계 통과 + 가드레일 위반 → **소병변만 개선(순이득 아님)** / 임계 미달 → **효과 없음** |

2×SD 는 3시드 평균에 대해서는 보수적인 벽이다(평균의 SE = SD/√3 이므로 약 **3.5 SE**). n = 60 구간에서
이보다 작은 차이는 잡음과 구분할 수 없다는 것이 아래 §3.2 의 측정 결과다.

## 3. 개입 전에 먼저 측정한 것 — "무엇이 잘못되고 있는가"

### 3.1 소병변은 학습에서 정말로 과소대표되는가 (H2 의 근거) [측정]

`scripts/analysis/small_lesion_stats.py`, train 1,015명 / 슬라이스 25,963장 / 양성 슬라이스 7,497장.

| GT 부피 구간 | 환자 수 | 환자 비중 | 양성 슬라이스 | **슬라이스 비중** | 환자당 양성 슬라이스 |
|---|---|---|---|---|---|
| [0, 2) mL | 284 | **28.0 %** | 768 | **10.2 %** | **2.70** |
| [2, 10) mL | 254 | 25.0 % | 1,504 | 20.1 % | 5.92 |
| [10, 50) mL | 290 | 28.6 % | 2,725 | 36.3 % | 9.40 |
| [50, ∞) mL | 187 | 18.4 % | 2,500 | **33.3 %** | **13.37** |

**가설의 전제는 사실이다**: 현 `SliceDataset` 은 양/음성만 균형을 맞추므로 소병변 환자는 코호트의 28 %인데
학습 슬라이스의 **10 %만** 차지한다. 대형 병변 환자는 18 %인데 33 %를 차지한다(환자당 4.9배).

가중 옵션이 이 비중을 어디까지 움직이는지도 사전에 측정했다(Kish 유효표본 ESS 병기).

| `slice_weight` | [0,2) 비중 | [50,∞) 비중 | ESS(슬라이스) | ESS/원본 | 최대 1인 점유 |
|---|---|---|---|---|---|
| `none` (현행) | 10.2 % | 33.3 % | 7,497 | 1.00 | 0.31 % |
| `inv_subject^1` | **28.0 %** | 18.4 % | 4,450 | 0.59 | 0.10 % |
| `inv_volume^0.5` | **36.2 %** | 10.4 % | 3,502 | 0.47 | 0.31 % |
| `inv_volume^1` | **69.2 %** | 1.6 % | 765 | **0.10** | 1.15 % |
| `inv_area^0.5` | 20.9 % | 18.0 % | 4,145 | 0.55 | 0.48 % |
| `inv_area^1` | 29.4 % | 11.0 % | 1,207 | 0.16 | 1.01 % |

`inv_volume^1` 은 소병변 비중을 7배 가까이 올리지만 유효표본이 **10 %로 붕괴**한다 — 그래서 세 단계
(`inv_subject^1` / `inv_volume^0.5` / `inv_volume^1`)를 용량-반응처럼 배치했다.

### 3.2 <2 mL 구간의 Dice 는 왜 낮고 왜 시끄러운가 [측정]

`scripts/analysis/small_lesion_failure_modes.py`, 기준선 **5 시드**의 val 60명.

| 항목 | s2026 | s7 | s77 | s123 | s777 |
|---|---|---|---|---|---|
| 구간 Dice 평균 | 0.5378 | 0.5378 | 0.5659 | 0.5294 | 0.5443 |
| 구간 Dice **중앙값** | 0.625 | 0.667 | 0.685 | 0.609 | 0.665 |
| **Dice = 0 인 환자 수** | **8/60** | **10/60** | **8/60** | **9/60** | **9/60** |
| 예측 마스크가 아예 빈 환자 | 3 | 6 | 5 | 2 | 6 |
| Dice=0 을 뺀 평균 | 0.621 | 0.645 | 0.653 | 0.623 | 0.640 |
| 0 들이 구간 평균에서 깎는 양 | −0.083 | −0.108 | −0.087 | −0.093 | −0.096 |
| **찾아낸 환자의 예측/GT 부피 중앙값** | **1.18** | **1.00** | **1.04** | **1.19** | **1.09** |
| 찾아낸 환자 중 과소분할 비율 | 0.38 | 0.48 | 0.50 | 0.35 | 0.43 |

**두 가지가 확정된다.**

1. **소병변에서 과소분할은 일어나고 있지 않다.** 모델이 찾아낸 소병변의 예측 부피는 GT 와 거의 같거나
   오히려 약간 크다(중앙값 비 1.00~1.19, 과소분할 환자 비율 0.35~0.50 = 동전던지기). 즉 **"소병변은 과소분할이
   문제이므로 FN 가중이 이론적으로 맞다"는 H5 의 전제는 이 데이터에서 거짓이다** — 개입 전에 알아낸 사실이고,
   §5.5 에서 Tversky 가 실제로 과대분할을 유발하며 실패하는 것으로 확인된다.
2. **구간 손실은 전부 "전부 아니면 전무"에서 온다.** Dice=0 인 8~10명을 빼면 이 구간의 Dice 는 0.62~0.65 로
   [2,10) mL 구간(0.656)과 사실상 같다. 낮은 구간 평균은 분할 품질이 아니라 **검출 실패의 산술 결과**다.

시드 간 안정성(같은 60명, 5 run):

| 항목 | 값 |
|---|---|
| 5 시드 전부 Dice = 0 (**하드 플로어**) | **7 / 60** |
| 5 시드 전부 Dice > 0 | 50 / 60 |
| 0 ↔ >0 을 오간 환자 | **3 / 60** (`sub-410`, `sub-832`, `sub-1393`) |
| 환자별 Dice 의 시드 SD 평균 | 0.054 |
| 구간 평균의 시드 SD (5 run) | **0.0138** |
| 위에서 "오가는 3명"을 제외해도 | 0.0149 |
| 환자 1명이 0 ↔ 중앙값 Dice 로 뒤집힐 때 구간 평균 이동량 | **0.0115** |

즉 **환자 1~2명의 검출 성패가 구간 평균을 0.01~0.02 움직인다.** 이것이 "기존 run 들의 소병변 Dice 가
0.541~0.579 로 흩어져 있다"의 정체다 — 실력 차가 아니라 n=60 의 이산성이다. 잡음의 대부분은
"오가는 3명"이 아니라 **나머지 50명의 Dice 가 함께 조금씩 흔들리는 것**에서 온다(3명을 빼도 SD 가 줄지 않는다).

### 3.3 못 찾는 7명은 모델 문제인가 입력 문제인가 [측정]

3 시드 전부 Dice = 0 인 7명을 A6 의 병변 대비 표(`results/a6/failures_val.csv`)와 대조했다.

| 항목 | 값 |
|---|---|
| 항상 실패하는 7명의 TRACE 대비 중앙값 | **+1.63 z** |
| 나머지 53명의 TRACE 대비 중앙값 | **+2.57 z** |
| <2 mL 구간에서 ADC 대비가 **양수**(급성 경색과 모순되는 라벨 서명, A6 발견)인 환자 | **2명** |
| 그 2명이 "항상 실패" 7명에 포함되는가 | **2/2 포함** (`sub-154`, `sub-212`) |

7명은 **입력 영상에서 병변 신호 자체가 약한 환자**들이고, 그 중 2명은 A6 가 "라벨이 급성 병변 서명과
반대"라고 플래그한 환자다. 샘플링 비중이나 손실 가중으로 도달할 수 있는 실패가 아니다 [측정 + 해석].

## 4. 개입 설계 (구현)

전부 **기본값이 현재 동작과 동일**하도록 추가했고, 기본 경로의 비트 재현성을 실측으로 확인했다(§6.1).

| 가설 | config 키 | 구현 위치 | 내용 |
|---|---|---|---|
| **H2** | `slice_weight: none\|inv_subject\|inv_volume\|inv_area` + `slice_weight_power` | `SliceDataset.resample` / `_positive_weights` | 매 epoch 양성 슬라이스를 **같은 개수만큼 복원추출**하되 확률을 병변 크기의 역수에 비례시킨다. 개수를 유지하므로 epoch 길이·step 수·LR 스케줄이 그대로다 |
| **H4** | `context: 0\|k` + `context_mode: all\|trace` | `stack_context()` (신규) + `SliceDataset.__getitem__` + `predict_subject` | 인접 ±k 슬라이스를 채널로 스택. `trace` = TRACE t−1,t,t+1 + ADC t (**4채널**), `all` = TRACE·ADC 각각 3슬라이스 (**6채널**). 볼륨 경계는 **복제 패딩**. 학습과 추론이 **같은 함수**를 쓰므로 어긋날 수 없다. 강도 증강은 **원 채널 그룹당 1회** 뽑아 인접 슬라이스에 공통 적용(슬라이스마다 따로 흔들면 문맥에 잡음을 넣는 꼴) |
| **H5** | `region_loss: dice\|tversky` + `tversky_alpha/beta/gamma`, `dice_reduction: sample_invsize` + `invsize_power` | `losses.tversky_loss` (신규), `soft_dice_loss` 확장 | Tversky = FN 을 FP 보다 무겁게(α 0.7 / β 0.3), focal Tversky(γ 1.33), 그리고 슬라이스별 Dice 를 **병변 픽셀 수의 −0.5 제곱**으로 가중(빈 슬라이스는 양성 슬라이스 가중의 평균을 받아 "sample" 대비 총영향이 보존된다) |

캐시 재생성은 필요 없었다(2.5D 는 기존 128² 캐시에서 슬라이스를 쌓는다). `data/cache*` 는 건드리지 않았다.

## 7. 결론과 인계

1. **소병변은 개선할 수 있다.** 원인은 A1/Astra 가 P0/P1 로 지목한 3D 문맥(H4)이 아니라, 아무도 보지 않았던
   **슬라이스 샘플러의 크기 편향**이었다. <2 mL 환자는 코호트의 28 %인데 학습 슬라이스의 10 %만 받고 있었다.
2. **권장 설정 (val 근거)**: `slice_weight: inv_volume`, `slice_weight_power: 0.5`.
   5시드에서 소병변 +0.030 · 전체 Dice +0.011 · ICC +0.035 · 민감도 +0.005 로 **모든 보고 지표가 함께 개선**된다.
   `configs/seg_unet2d_invvol.yaml` 로 별도 저장했다. **기존 config·체크포인트는 변경하지 않았다.**
3. **하지 않은 것**: test 재평가. 헌장 §C 는 "재학습·재선택 금지"이고 test 는 이미 1회 열렸다. 이 결과는
   **다음 학습 사이클의 근거**이지 현재 보고 수치를 바꾸는 근거가 아니다. `runs/small_*` 의 어떤 모델도
   test 에 올리지 않았다.
4. **기각된 것을 그대로 남긴다**: 해상도(H1), `dice_reduction: sample`(H3), 2.5D 문맥(H4, 4·6채널 모두),
   Tversky/focal-Tversky FN 가중(H5 전반부), 추론 임계값 조정(H6). 특히 **H5 의 FN 가중은 전제 자체가 틀렸다** —
   이 데이터의 소병변은 과소분할이 아니라 미검출이 문제이므로, FN 을 무겁게 하면 과대분할만 늘고 Dice 는 내려간다.
5. **남은 한계**: (a) <2 mL 의 하드 플로어 4명은 입력 영상에 병변 증거가 약해 어떤 샘플링·손실로도 도달하지
   못했다 — 데이터/라벨 문제다. (b) `inv_volume^1` 처럼 강하게 걸면 소병변은 더 오르지만 부피 ICC 가 무너진다
   (0.878 → 0.834). (c) 모든 판정은 **val 218명·소병변 60명** 위의 것이고, val 로 epoch 을 고르는 구조도 그대로다.
   (d) 시드 5개는 여전히 적다 — ICC 의 시드 SD 가 0.042 라 ICC 의 +0.035 는 **1시드 SD 이내**이므로
   "ICC 가 확실히 좋아졌다"고까지는 말할 수 없고, "나빠지지 않았다"가 정확한 표현이다.
