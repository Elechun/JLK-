**결론 3가지** [측정]
1. **"macro AUC > 0.60" 은 아무 학습 없이 GT 부피 한 개(0.6421)로 통과한다** → 기준으로서 무의미하다.
2. **"크기 제외"라는 이름이 틀렸다.** `no_size` 는 `full` 보다 오히려 높고(0.7376 vs 0.7301, GT),
   그 SVO AUC(0.873)는 `size_only`(0.837)보다도 높다. `n_components`(ρ=+0.476)·`NIHSS`(ρ=+0.471)가
   부피 대리변수이기 때문이다.
3. **크기 신호는 전부 SVO 라벨 정의에서 온다.** SVO 를 빼면 부피 단독 macro 가 0.6421 → **0.5125**(CI 가 0.5 를 포함)로 무너지는 반면,
   `full` 은 0.6551(CI 하한 0.603)을 유지한다. → **모델이 실제로 아는 것은 "작은 병변 = SVO" 가 아닌 다른 무엇**이며,
   그 크기를 재는 지표가 새 기준 E2·E3 다.

### 2-2. "크기 제외 세트"를 스케일 불변으로 재정의한다 — **판정: 예** [측정]

log 부피와의 Spearman ρ (dev 447명, GT 마스크):

| 특징 | ρ | 판정 |
|---|---:|---|
| `volume_ml` / `log_volume_ml` | +1.000 | 크기(정의상) |
| `largest_component_ml` | +0.980 | 크기 |
| `n_slices_involved` | +0.884 | 크기 |
| `z_extent_frac` | +0.774 | 크기 |
| `spread_x_norm` / `spread_y_norm` | +0.746 / +0.745 | **크기 대리** — 이름은 무차원이지만 실제로는 병변 크기 |
| **`n_components`** | **+0.476** | **크기 대리** (A2 F4 재확인) |
| **`nihss`** | **+0.471** | **크기 대리** — 임상변수조차 부피의 대리다 |
| `bilateral` | +0.421 | 크기 대리(성분 수 의존) |
| `laterality_left_frac` | −0.415 | 크기 대리(대형 병변은 한쪽 반구를 통째로 덮어 포화) |
| `multi_territory_proxy` | +0.395 | 크기 대리 |
| `centroid_z_norm` | +0.172 | **유지** |
| `largest_component_frac` | −0.101 | **유지** |
| `age` | −0.095 | **유지** |
| `centroid_x_norm` / `centroid_y_norm` / `sex_male` | −0.021 / +0.008 / −0.006 | **유지** |

→ **`scale_invariant` = {`largest_component_frac`, `centroid_x_norm`, `centroid_y_norm`, `centroid_z_norm`, `age`, `sex_male`}**
(기준: **구성상 무차원** ∧ **dev 에서 \|ρ\| < 0.25**. 두 조건을 모두 요구해 순수 데이터 주도 선택이 되지 않게 했다.)

이 세트의 결과가 시사하는 것 [측정]: macro 0.6522(부피 단독 대비 +0.010, CI 가 0 을 포함 → 유의하지 않음)이지만
**LAA-vs-CE 는 0.6434 로 `full`(0.6551)에 근접**하고, **SVO 제외 3클래스에서는 0.6641 로 `full`(0.6551)을 넘는다**.
즉 **크기를 완전히 뺀 뒤에도 남는 신호는 "병변이 어디에 있는가"(centroid) 와 "얼마나 뭉쳐 있는가"(largest_component_frac)** 이며,

## 10. A6 자신의 한계

- 병인 분류의 **`C=0.5`, logreg, 5-fold** 는 A6 가 재검증하지 않았다(A2·이전 세션이 정한 값을 그대로 썼다).
  하이퍼파라미터를 dev 에서 다시 고르면 dev 수치가 낙관적으로 오르므로 **일부러 건드리지 않았다**.
- test 코호트의 병인 클래스 분포는 **층화 비율에서 추정**한 값이고 실측이 아니다.
- §6 의 "라벨에 근거가 없다"는 판정은 **정규화된 캐시 영상의 대비 통계**에 근거한 것이며, 원본 DICOM/NIfTI 를
  방사선학적으로 판독한 것이 아니다 [추정]. 11명 전원을 육안 확인하지는 않았다.
- ICC 의 **시드 간** 변동(A4 측정 ±0.05)은 A6 가 재측정하지 않았다. 보고한 CI 는 **같은 모델에 대한 환자 재표본** CI 이며,
  "다시 학습했을 때의 변동"은 포함하지 않는다.
- `dice_reduction`·ADC ablation 판정은 **A4 의 단일 시드 실험**을 인용한 것이고 A6 가 재실행하지 않았다.
