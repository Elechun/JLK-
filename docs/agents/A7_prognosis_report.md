## 0. 요약 (7줄)

1. **mRS 결측은 무작위가 아니다.** 보유 620 vs 결측 831 은 병변 부피(중앙값 15.1 vs 5.3 mL, log 기준 SMD +0.372),
   NIHSS(7 vs 3, SMD +0.435), 장비(Philips 100 % vs 97.1 %)에서 크게 다르다 → **퇴원 mRS 는 중증 환자에게서 더 잘 기록된다** [측정].
2. 이 편향의 절반은 A2 F5 가 찾은 "임상변수 전 결측 단일 블록"(eligible 기준 **503명**)이고, **나머지 328명은 임상변수는 있는데 mRS 만 없고
   병변이 더 작다(중앙값 3.68 mL·NIHSS 3)** → 블록으로 설명되지 않는 추가 편향이 있다 [측정].
3. **중첩 CV(외부 5-fold × 5반복 / 내부 5-fold) 결과: 영상 포함 선택 절차 AUC 0.8209 [0.7865, 0.8538]**,
   기준선은 임상 단독 **0.7673**, NIHSS 단독 **0.7557**, 부피 단독 **0.7416** [측정].
4. **짝지은 부트스트랩 ΔAUC(영상 포함 − 임상 단독) = +0.0536 [+0.0265, +0.0841]**, 25개 외부 fold 전부에서 양수.
   병인 분류와 달리 **영상이 임상변수 위에 값을 더한다** [측정].
5. **선택기에 임상 단독 후보를 넣어도 25개 외부 fold 중 24개에서 영상 포함 후보가 선택된다**(argmax 규칙에서는 25/25) [측정].
6. **예측 마스크가 GT 마스크보다 낫다**(0.8209 vs 0.8068) → GT 는 성능 상한이 아니라 오라클 입력 참조다 [측정]. 병인 과제와 같은 패턴.
7. **동결 주 모델**: `clinical_lesion_all`(임상 4 + 병변 15 = 19특징) + HistGradientBoosting(depth 2, min_leaf 40).
   **사전 등록 주 판정 기준 = test AUC ≥ 0.70**(검정력 0.995 @ 참값 0.8209, 0.979 @ 0.80, 우연일 때 오통과 0.0009)
   **+ 일반화 밴드 |AUC_test − 0.8209| ≤ 0.10**(오경보 4.4 %). 시뮬레이션 PASS/판정불가/FAIL = **0.992 / 0.000 / 0.008**.
   **영상 증분은 게이트가 아니라 부차 보고**다 — n=82 에서 CI 하한 > 0 규칙의 검정력은 0.304 뿐이고 80 % 에는 n≈308 이 필요하다.

### 2-4. 결론과 제약 (사전 선언 — 결과와 무관하게 보고서·README 에 남긴다)
> **mRS 결측은 MCAR 이 아니며, 방향은 "경증일수록 결측"이다.**
> 1. 분석 코호트 538명은 **중증 쪽으로 치우친 표본**이고, 관측된 양호:불량 = 265:273 ≈ 50:50 은 **모집단 유병률이 아니다**.
> 2. AUC(순위 지표)는 표본 유병률에 비교적 둔감하지만, **PPV·NPV·캘리브레이션·Brier 는 유병률에 직접 의존**하므로
>    다른 코호트로 이전되지 않는다. 이 값들은 "이 표본 안에서"라는 단서를 항상 붙인다.
> 3. **비-Philips 24명 중 mRS 보유자는 0명**이다 → 장비 일반화는 이 과제에서 **검증 불가**(아예 측정할 수 없다).
> 4. SVO(소혈관 폐색, 정의상 <1.5 cm)가 결측군에 과대표집(0.134 vs 0.068)돼 있다 → **소병변 환자에서의 성능은 과소 검증**된다.
> 5. **결측 보정(IPW·다중대입)은 하지 않았다.** 결측을 설명할 만한 관측 변수가 부족하고(블록 503명은 공변량 자체가 없다),
>    보정을 하면 검증 불가능한 MAR 가정을 새로 얹게 된다. **보정하지 않았다는 사실 자체를 한계로 남긴다.**

### 3-4. 중첩 CV 설계 (A5a 지적 8 의 교훈)
- **외부** 5-fold(층화) × **5 반복**(seed 2026+r) → 반복별 pooled OOF 확률을 평균해 헤드라인 값으로 쓴다.
- **내부** 5-fold: 외부 학습 fold **안에서만** 후보 28개(특징집합 × {logreg C∈{0.03,0.1,0.3,1.0}, HGB(d2,leaf40)·HGB(d3,leaf20)})의
  AUC 를 재고, 규칙을 적용해 1개를 고른 뒤 외부 test fold 에 적용한다.
- **후보 풀 2종**: `imaging`(영상 특징을 포함한 후보만) / `unrestricted`(기준선 후보까지 포함).
  두 풀은 **같은 내부 점수**를 공유하므로 비교가 공정하다.
- **선택 규칙 2종**: `argmax`(내부 AUC 최대) / `one_se`(최고값의 1 SE 이내 중 가장 단순한 모델 — Breiman 1984, ESL §7.10).
- **기준선 3종은 선택 대상이 아니라 고정 설정**(logreg C=0.3)으로 **같은 외부 fold** 에 재적합 → 모든 Δ 가 짝지어진다.
- 클래스 가중치는 쓰지 않는다(결과가 거의 균형이고 캘리브레이션이 보고 항목이라 가중치는 위험만 늘린다).

### 5-1. 동결 절차와 결과
같은 내부 CV 선택 규칙(argmax)을 **dev 538명 전체에 1회** 적용한 결과:

| 3 | `clinical_lesion_core` + HGB(d=2, leaf=40) | 0.8224 ± 0.0173 |
| 4 | `clinical_lesion_core` + HGB(d=3, leaf=20) | 0.8174 ± 0.0203 |
| 5 | `clinical_volume` + HGB(d=2, leaf=40) | 0.8083 ± 0.0130 |

> **동결 = `clinical_lesion_all` + HistGradientBoostingClassifier(`max_depth=2`, `min_samples_leaf=40`,
> `learning_rate=0.05`, `max_iter=200`, `l2_regularization=1.0`, `early_stopping=False`, 클래스 가중치 없음, `random_state=2026`),
> 입력은 예측 마스크.** `results/prognosis/frozen_model.json` 에 기록. test 에서 변경 불가.

**선택 규칙을 고른 과정에 대한 정직한 기술**: A7 은 argmax 와 1-SE 두 규칙을 **중첩 CV 로 둘 다 측정한 뒤** argmax 를 골랐다.
근거는 argmax 가 **AUC(0.8209 vs 0.8134)와 캘리브레이션 기울기(0.966 vs 1.192) 둘 다에서 앞선다**는 것이다 [측정].
중첩 CV 값 자체는 각 규칙에 대해 편향이 없지만, **두 값 중 큰 쪽을 고른 만큼의 작은 낙관**이 남는다.
그래서 §5-3 의 검정력 표에는 **참값이 0.80(보수적)인 경우를 반드시 함께** 싣는다.
또한 과제 지시는 "로지스틱 회귀(주)"였으나 **사전 등록한 선택 규칙이 HGB 를 골랐으므로 규칙을 따랐다.**
로지스틱 대안(`clinical_volume|logreg`, 5특징, 단순 CV 0.7973)의 값을 §4-4 에 나란히 남긴다.

### 5-3. 사전 등록안 (test 를 열기 전 확정) — 헌장 §"확장 과제 — 예후 예측 (사전 등록 v1)" 과 동일

**주 판정 기준 P1 — 절대 AUC ≥ 0.70 (점추정) ∧ 부트스트랩 CI 하한 > 0.50**

*임계값 근거*: 0.70 은 Hosmer–Lemeshow–Sturdivant, *Applied Logistic Regression* 3판(2013) 이 제시하는
"acceptable discrimination" 구간(0.7–0.8)의 하한이다. 즉 **자의적 절충값이 아니라 인용 가능한 기준**이다.

*검정력* [측정+산술, `results/prognosis/power.json`] — Hanley–McNeil (1982), test n=82,
클래스 비는 dev 비율(50.7 % 불량)을 옮겨 n1=42(불량)/n2=40(양호)로 **추정**:

| 임계값 | 참값 0.8209 (dev nested) | 참값 0.80 (보수) | 참값 0.767 (임상 단독 수준) | 참값 0.756 (NIHSS 수준) | 참값 0.5 (우연) 오통과 |
|---:|---:|---:|---:|---:|---:|
| 0.60 | 1.000 | 1.000 | 0.999 | 0.998 | 0.0596 |
| 0.65 | 1.000 | 0.999 | 0.988 | 0.976 | 0.0097 |
| 0.68 | 0.999 | 0.993 | 0.953 | 0.922 | 0.0025 |
| **0.70 (채택)** | **0.995** | **0.979** | 0.901 | 0.852 | **0.0009** |
| 0.72 | 0.985 | 0.949 | 0.817 | 0.749 | 0.0003 |
| 0.75 | 0.936 | 0.846 | 0.630 | 0.543 | 0.00002 |

test AUC 의 SE = **0.0466**(참값 0.8209 가정), 기대 95 % CI 반폭 **±0.091**. 우연일 때 SE = 0.0642.
클래스 비 가정 민감도: 불량 비율 0.40~0.60 에서 SE 는 0.0466~0.0475 로만 변한다 → 가정이 결론을 바꾸지 않는다 [측정].

*"판정 불가" 가 대량 발생하지 않는가* — **E1 의 실패를 반복하지 않기 위한 확인.**
E1 은 점추정 게이트 검정력이 0.93 인데도 "CI 하한 > 0.5" 조항 때문에 실제 PASS 가 0.54, 판정불가가 0.40 이었다(A5b 시뮬레이션).
여기서는 dev 값이 0.82 로 높고 SE 가 0.047 이라 **CI 하한이 0.5 이하로 내려가려면 AUC 추정치가 ≈0.597 이하여야 한다**.
참값 0.80 에서 그 확률은 정규근사로 **2e-05** 이며, 이항모형 시뮬레이션(§5-4)에서도 판정불가는 사실상 0 이다 → **조항이 사실상 무료다.**

**주 판정 기준 P1b — 일반화 밴드 |AUC_test − 0.8209| ≤ 0.10**

P1 은 여유가 크다(참값이 dev 값이면 통과 확률 0.995). 헌장이 S1 에 대해 지적한 것과 같은 문제
("여유가 7 SE 라 변별력이 없다")이므로, **S1b 와 같은 구조의 두 번째 기준**을 둔다.
dev 부트스트랩 SD 0.0172 + test SE 0.0466 → 차이의 SD **0.0497** → 밴드 0.10 은 **2.01 SD**,
참 차이가 0 일 때 오경보 **4.4 %** [측정+산술]. (0.08 이면 오경보 10.7 %, 0.12 면 1.6 % — 0.10 이 S1b 의 2.2 SE 와 가장 가깝다.)
**즉 실제로 정보를 담는 기준은 P1 이 아니라 P1b 다.**

**부차 보고 P4 — 영상의 증분 (게이트 아님)**

dev 중첩 CV Δ = **+0.0536 [+0.0265, +0.0841]**, 짝지은 부트스트랩 SD **0.0145**(n=538).
같은 Δ 를 n=82 에서 재면 SD 가 √(538/82) = **2.56배**인 **≈0.037** 이 된다 → "CI 하한 > 0" 규칙의 검정력은 **0.304** 이고,
80 % 검정력에는 **n ≈ 308** 이 필요하다 [추정, `results/prognosis/power.json`].
따라서 **P4 는 게이트로 걸지 않는다.** 주 근거는 dev 중첩 CV 값이고, test 값은 CI 와 함께 **참고치**로만 싣는다.
**test 에서 Δ 의 CI 가 0 을 걸치는 것은 정상이며, 그것을 "영상이 기여하지 않는다"로 읽지 않는다** — 이 문장을 사전에 못 박는다.

**그 밖의 보고 의무**: 캘리브레이션(Brier, Brier skill, 기울기·절편, 5분위 표), 혼동행렬(0.50 과 dev Youden 0.4562 두 곳),
세 기준선의 test AUC + CI, GT 오라클 대조, 순서형 보조(Spearman/MAE), NIHSS 층별·seg-train/val 층별, 사망(mRS 6) 탐색적 분석.

### 6-2. 하위군
| 하위군 | n | 불량 | 동결 모델 AUC | 임상 단독 AUC | Δ |
|---|---:|---:|---:|---:|---:|
| NIHSS < 5 (경증) | 200 | 47 | 0.695 | 0.605 | **+0.090** |
| NIHSS ≥ 5 | 338 | 226 | 0.794 | 0.662 | **+0.132** |
| 분할 모델 train 부분 | 443 | 218 | 0.834 | 0.776 | +0.058 |
| 분할 모델 val 부분 | 95 | 55 | 0.820 | 0.726 | +0.094 |
| 사망(mRS 6) 판별 — **탐색적** | 538 | 37 | 0.823 | 0.774 | +0.049 |

- A1b 는 "NIHSS 가 강해서 영상 기여가 가려질 수 있고, 경증군에서 영상 기여가 클 것"이라고 예상했다.
  **측정 결과는 반대다**: 절대 AUC 는 경증군에서 낮고(0.695), 증분은 중증군에서 더 크다(+0.132).
  다만 하위군 안에서는 AUC 가 층 안의 좁은 NIHSS 분포로 계산되므로 전체 AUC 와 직접 비교할 수 없다.
- **seg-train 0.834 vs seg-val 0.820**: 분할 모델의 train 이었던 환자의 예측 마스크가 더 깨끗하다는 낙관 편향(헌장 한계 6)의
  예후 판(版)이다. 차이 0.014 는 n=95 의 SE(≈0.045) 안이지만 **방향은 낙관 쪽**이므로,
  **test 가 dev 보다 낮게 나오는 것은 예상 범위**다. P1b 의 0.10 밴드가 이를 흡수하도록 설계했다.
- 사망 37명 분석은 **모델이 그 라벨로 학습된 적이 없는** 탐색적 분석이다.

   회귀 테스트 3개가 이를 고정한다.
2. **`--final` 은 이 세션에서 한 번도 실행되지 않았다.** `results/prognosis/` 에 `*_final*` 산출물이 **0건**이다 [측정].
3. `results/prognosis/` 의 **모든 파일에서 test 218명의 `participant_id` 출현 횟수 = 0** [측정].
4. `scripts/analysis/a7_missingness.py` 는 `data/index.csv` 만 읽으며 mRS **값**을 쓰지 않는다 — 군 구분은 `notna()` 뿐이고,

5. `scripts/analysis/a7_power.py` 는 test 클래스 비를 **dev 비율에서 추정**하며 test 라벨을 읽지 않는다(스크립트 docstring 에 명시).

## 9. A7 자신의 한계

1. **선택 규칙을 2개 재고 더 나은 쪽을 골랐다** — 중첩 CV 값은 각 규칙에 대해 편향이 없지만, 두 값 중 최댓값을 고른 만큼의
   작은 낙관이 남는다. 그래서 검정력 표에 참값 0.80 을 병기했다.
2. **HGB 를 동결했다.** 과제 지시의 "로지스틱 회귀(주)"와 다르며, 트리 앙상블은 19특징·538명에서 이전성이 더 나쁠 수 있다.
   중첩 CV 와 캘리브레이션 둘 다 argmax(=HGB)를 지지했기 때문에 규칙을 따랐지만, **test 에서 로지스틱 대안보다 나쁘게 나올 가능성**은 열려 있다.
3. **결측 보정을 하지 않았다.** IPW·다중대입을 하면 결과가 달라질 수 있으나, 검증 불가능한 MAR 가정을 새로 얹게 된다.
4. **하위군 분석의 n 이 작다**(경증 200명 중 불량 47명, 사망 37명). CI 를 붙이지 않았고 탐색적이다.
5. **`scripts/train_prognosis.py --final` 을 실행해 본 적이 없다** — 규칙상 실행할 수 없기 때문이다.
   코드 경로는 합성 데이터 테스트로만 검증했다. 오케스트레이터는 실행 전에 `--final` 분기를 한 번 눈으로 확인하는 것이 좋다.
6. `results/a6/power.json` 은 A5b 의 좌우축 수정 **이전** 값(dev LAA-vs-CE 0.6551)으로 저장돼 있어 현재 `results/cls_pred_logreg.json`(0.6709)과
   불일치한다 [측정]. A7 이 만든 문제가 아니고 A6 의 산출물이므로 **덮어쓰지 않았다**. 재생성하면 E1 검정력이 0.93 → 0.95 로 올라간다.
7. 예측 마스크가 GT 마스크보다 나은 이유(§4-5)는 **가설만 제시했고 검증하지 않았다**.
